# AML-GraphRx

Analysis code supporting **Graph-informed analysis identifies a reproducible pathway expression contrast in acute myeloid leukemia**.

This release is aligned with the supplied `AML_GraphRx.docx` and `AML_GraphRx_supplementary.docx`. Exact file identities are recorded in `provenance/reviewed_sources.json`. Eighteen analysis scripts were curated from the executed project notebooks. The archive includes real source tables, the frozen pathway definition, seed settings, figure code and verification code. No new scientific analysis or favorable-seed selection has been added.

## Start here

To check the included results without Google Drive, a GPU or raw expression data:

```bash
python -m pip install -r requirements-replay.txt
python tests/check_release.py
python code/verify_key_results.py
python code/check_conditional_resampling.py
python code/make_figures.py
```

The last command recreates the nine data figures (Figures 2–6 and S1–S4), with PNG at 600 dpi, SVG and PDF output. The workflow illustration, graphical abstract and manuscript are not regenerated by this code. Figure 3A shows coverage and Figure 3B shows recurrent-community counts, preserving the archived plotting code.

## Re-run a project analysis

These scripts begin from the project's **locked, prepared inputs**. They are not a raw-GEO-to-publication installer. The historical R preparation notebooks contain earlier branches and interrupted repairs and have deliberately not been relabeled as a clean end-to-end workflow. Input contracts and source preparation audits are described in `docs/INPUTS.md`.

```bash
python run_analysis.py --list
python run_analysis.py conditional_association --project-root /absolute/path/AML_GraphRx
```

Install the applicable dependencies first; see `docs/ENVIRONMENT.md`. `notebooks/Run_manuscript_analysis_Colab.ipynb` mounts Drive and runs a selected script. Use a working copy when re-executing historical scripts. Several original scripts deliberately refuse to replace a pre-existing output when its bytes differ, and several historical protocol files contain timestamps or absolute paths. A packaging check is not a claim that every historical branch has been rerun from raw data.

## Seeds and scientific scope

- Original discovery and expression PCA: **20261004**.
- Gaussian controls: **20261011, 20261012, 20261013, 20261014, 20261015**.
- Gene-row shuffles: **20261021, 20261022, 20261023, 20261024, 20261025**.
- Three paired message-ablation initialization seeds: **20261031, 20261101, 20261102**.
- Rewiring base seed: **20261029**, incremented by relation index; one topology reused across all three fits.

All additional seeds, offsets, resampling counts and their manuscript locations are in `docs/SEED_CONCORDANCE.md` and `config/random_settings.json`. Seed values are integer random-number settings, not dates. Do not collapse different analyses to one common seed.

The original discovery and representation controls normalize the gene basis before projection. All nine message-ablation fits project raw latent outputs. The amended cross-seed code preserves that executed treatment. All message-ablation arms retain biological decoder targets. The proposed normalization-aligned sensitivity is not part of this release because it was not performed for the manuscript.

The reproducible endpoint is the continuous pathway expression relationship. The scripts do not establish clinical treatment selection, survival prediction or externally validated discrete AML subtypes.

## File map

- `analysis/`: manuscript-linked analysis scripts, with descriptive filenames.
- `config/analyses.json`: script-to-paper mapping.
- `source_tables/`: authentic frozen definitions, protocols and reported outputs.
- `code/`: figure reconstruction and verification of existing results.
- `provenance/`: hashes and exact notebook/cell lineage.
- `docs/`: seeds, inputs, environment and publication instructions.
- `verification/`: generated local checks; see `docs/VALIDATION.md` for checks performed for this release.

Historical output identifiers remain inside filenames and manifests so that existing input hashes and dependencies remain traceable. They are not used as the scientific names of analyses in the README.

## Data, attribution and release metadata

The GEO accessions, BeatAML and DepMap release are identified in the manuscript and input guide. Raw expression matrices, private Drive links, checkpoints, access tokens, manuscripts and patient-level clinical master files are not bundled as repository inputs. Included score tables retain the public study identifiers used for reproducibility.

No author names, DOI, repository URL or software license have been invented. Add the actual author attribution and an author-approved license before public release. The repository has not been published automatically. See `docs/GITHUB_UPLOAD_FA.md`.
